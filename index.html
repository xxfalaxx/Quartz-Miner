Manage your mining session

Pool controls

Test pool connections without a wallet, save Stratum destinations, and choose Pool or Solo where supported. Failover tries reachable servers at the same pool.

GPU tuning

Monitor hashrate, power and temperature. Adjust supported GPU settings, set a fan temperature target, save profiles and reset a board to factory settings.

Share diagnostics

Track accepted, stale and rejected shares. Copy the session log and check recent block candidates against Pearl’s canonical chain.

GPU compatibility

Requires Windows x64 and a compatible NVIDIA driver. The ZIP bundles the application runtimes.
